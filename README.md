# Wedding Invite

Свадебное приглашение — одностраничный сайт на React + Vite + Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build     # собирает в dist/
npm run preview   # локальный просмотр сборки
```

## Деплой

Проект разворачивается на Vercel (`vercel.json` уже настроен: framework `vite`,
output `dist`). Достаточно импортировать репозиторий на [vercel.com/new](https://vercel.com/new).
